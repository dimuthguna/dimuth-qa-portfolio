Jira JQL Queries — Project 10

Query 1: Filter tickets by status
project = SCRUM AND status = "To Do"

Query 2: Filter tickets by issue type (bugs only)
project = SCRUM AND issuetype = Bug

Query 3: Sort all tickets by priority
project = SCRUM ORDER BY priority DESC
